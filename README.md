# LLMAPI

Este projeto é uma API simples em .NET 8, que consulta dados de carros a partir de um banco de dados PostgreSQL.

## Requisitos

- .NET 8 SDK
- Docker (se for usar containers)
- PostgreSQL (se não usar Docker)
